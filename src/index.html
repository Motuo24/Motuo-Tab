引言

这里收录了本 tab 页的教程，让您获得更好的体验。左侧为章节导航，点击即可跳转到对应内容。

配置 AI 助手

点击 AI 助手面板右上角的 ⚙ 打开配置面板，填入下面的三项即可开始对话：

API 地址 填供应商开放接口，支持两种写法：
  • 完整路径，如 https://open.bigmodel.cn/api/paas/v4/chat/completions
  • 仅域名，如 https://api.deepseek.com（会自动补全 /v1/chat/completions）
API Key 到模型平台创建，注册后生成 sk- 开头的密钥。例如：
  • DeepSeek：platform.deepseek.com
  • 智谱：open.bigmodel.cn
模型名称 填该平台提供的模型名，如 deepseek-chat、glm-4-flash。

密钥仅保存在本地浏览器（localStorage），不会上传到任何服务器。

如何获取博查AI密钥

勾选 AI 面板底部的「联网搜索」后，AI 会搜索互联网获取实时信息（天气、新闻、股价等）。联网需要「博查AI 密钥」：

  1. 打开 open.bochaai.com 并注册 / 登录
  2. 进入「API 密钥」页面，创建并复制 Key（sk- 开头）
  3. 回到本页 ⚙ 配置，填入「博查AI 密钥」，再勾选「联网搜索」

未填密钥时勾选联网搜索，会给出提示提醒补填。

键盘快捷键

  • Esc：关闭当前弹窗 / 菜单
  • Ctrl+E / ⌘+E：切换专注模式并聚焦搜索框
  • Ctrl+K / ⌘+K：切换编辑页面（拖动排序 / 拖到底部删除）
  • Ctrl+A / ⌘+A：快速打开 AI 助手
  • Ctrl+V / ⌘+V：在「添加快捷方式」弹窗里粘贴图片作为图标

搜索直达 & 使用技巧

  • 站内搜索直达：搜索框输入 bl 关键词（B站）、zh（知乎）、gh（GitHub）、tb（淘宝）、db（豆瓣）
  • 自定义搜索引擎：搜索框左侧图标下拉，底部可添加自己的搜索引擎
  • 管理卡片：右键快捷方式可「新标签页打开 / 编辑 / 删除 / 复制链接」；编辑模式下可拖动排序
  • 数据备份：菜单「通用配置」→ 导出备份，可迁移全部数据
